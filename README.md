## 📌 PROJECT OVERVIEW

This Excel project analyzes customer transaction data and presents key insights through an interactive and visually appealing dashboard.

## 📂 DATASET

• 📊 Dataset: Customer Transaction Dataset  
• 🔢 Total Records: 200+  
• 🧾 Key Fields: Transaction ID, Date, Customer ID, Customer Name, Product ID, Product Name, Category, Quantity, Unit Price, Payment Method, Region, Customer Segment, Customer Since, Total Amount

## 📑 SHEET ORGANIZATION

• 📥 **Data Intelligence Dashboard** – Original transaction dataset with helper columns  
• 🔎 **FILTER ANALYSIS** – Multi-value filtered transaction analysis  
• 🏆 **HIGH VALUE CUSTOMERS** – High-value customer analysis and Top 10 customers  
• 📊 **FREQUENCY ANALYSIS** – Most frequently purchased products, list comparison and abbreviations  
• 📈 **REGRESSION ANALYSIS** – Linear regression analysis using Excel Data Analysis ToolPak  
• 🧮 **Scenario Summary** – What-If Scenario Manager results  
• 📊 **Dashboard** – Final interactive dashboard with PivotTables and PivotCharts  
• 📅 **WEEKLY DATA** – Weekly sales analysis and PivotTable

## 🧹 DATA ANALYSIS

• 📅 Date & Time Functions – TODAY, NOW, DATEDIF, EOMONTH  
• 🔎 FILTER – Multi-value transaction filtering  
• ➡️ Conditional Formatting – Icons and Arrows  
• 🕒 Timestamp – Created using NOW and iterative calculations  
• 🎯 Scenario Manager – Best Case, Normal Case and Worst Case  
• 🎯 Goal Seek – Target Total Amount analysis  
• 📈 Linear Regression – Quantity vs Total Amount  
• 🏆 High-Value Customers – Top 10 customers based on total purchase  
• 🔁 Most Frequently Purchased Product – Product purchase frequency analysis  
• 🔗 Compare Two Lists – Extracting matching customer names  
• 🔤 Abbreviations – Creating customer initials using TEXT functions

• 🌎 Region Slicer

• 📅 Monthly Sales Trend  
• 📆 Weekly Sales Trend

## 💡 HOW TO USE

Use the slicers and timeline on the Dashboard to filter the transaction data.

The PivotTables, PivotCharts and KPI indicators update according to the selected filters, allowing users to explore customer transactions, product performance, regional sales and time-based sales trends.

## 🎯 PROJECT OBJECTIVE

The objective of this project is to analyze customer transactions, identify high-value customers and frequently purchased products, perform advanced Excel analysis, and present meaningful insights through an interactive and easy-to-understand Excel dashboard.

## 🚀 PROJECT HIGHLIGHT

Transforming raw customer transaction data into meaningful business insights using Excel's advanced formulas, What-If Analysis, Linear Regression, PivotTables, PivotCharts, Slicers, Timelines and interactive dashboard capabilities.
